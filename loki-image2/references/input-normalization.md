# 输入归一化

只使用当前会话实际提供的文档读取、转录、OCR 或视觉理解能力。对同一输入归一化一次，后续模式共用结果。

## 统一字段

| 字段 | 含义 |
|---|---|
| `source_type` | `text`、`document`、`audio` 或 `image` |
| `source_language` | 检测到的原始语言；不等于输出语言 |
| `topic` | 单张图要表达的核心主题 |
| `audience` | 目标受众及其知识水平 |
| `purpose` | 演示、社媒、教学、报告、海报、封面等用途 |
| `facts` | 可由输入直接支持的数据、名称、日期、术语与结论 |
| `hierarchy` | 标题、核心结论、3–6 个关键模块及其关系 |
| `verbatim_text` | 必须逐字保留的标题、引文、术语、数字或标签 |
| `visual_cues` | 可见对象、构图、色彩、关系、动作和需保留特征 |
| `constraints` | 用户限制、禁用项、比例候选、语言与合规要求 |

## 按输入类别处理

- **文本**：直接读取，识别主题、事实、层级、重复与必须逐字保留的文字；不要把整段原文机械复制进画面。
- **主流文档**：用当前可用文档工具提取正文、标题层级、表格和图片说明；表格数据保持行列语义。扫描件只有在 OCR 可用时读取。
- **音频**：用当前可用转录能力生成带语言信息的文本；区分说话内容与转录不确定项，不把听不清内容补成事实。
- **图片**：用视觉能力提取可见文字、主体、构图、颜色、关系和用户指定的保留特征。把“看到的观察”与“基于观察的推断”分开标注。

## 保真规则

1. 原样保留 `facts` 与 `verbatim_text` 中的数字、比例、日期、姓名、品牌名和专业术语。
2. 删除重复或口语填充时，不改变因果、比较、顺序或结论。
3. 来源未给出的数字、引用、案例或结论标为未知，不擅自补充。
4. 语言选择遵循用户指定；未指定时中文转为简体中文，其他语言保持原文，不隐式翻译。
5. 所需读取、转录、OCR 或视觉能力缺失、文件损坏或内容无法读取时，明确说明并停止，不推断或编造内容。

视频输入在 v1 不支持，拒绝抽帧、转录或假定视频内容；请用户改给文本、音频、图片或受支持文档。
