# Prompt 系统

先完成归一化和内容方案，再组装一份 Provider 无关的最终 Prompt。不要复制十二份完整模板。

## Loki 角色锚点

主要角色保持：Q 版小幽灵少年、约 2.5–3 头身、蓬松尖翘的纯白短发、大红眼、粗黑眉、顽皮自信微笑、半透明白或淡蓝白身体、花瓣/火焰感衣摆、无双腿、弯曲漂浮尾巴。整体聪明、友好、有行动力，不恐怖。

默认只放 1 个主要角色；必要时加 1 个小签名，角色总面积不超过约 15%–20%，不得挡标题、数据、流程或正文。动作服务内容：指重点、思考、操作电脑、说明、点赞、观察、推动模块、抱数据卡或引导阅读。

按空间与媒介选择简化变体：

- **小尺寸/高密度**：只保留尖翘白发、红眼、粗眉、微笑、水滴幽灵身和弯尾。
- **白板/黑板**：马克笔或粉笔简笔画。
- **蓝图/科技**：白色技术线稿或克制全息角色，红眼点睛。
- **中国/手账**：水墨小灵体或水彩贴纸。
- **复古/扁平/黏土**：统一媒介的粗描边卡通、圆润矢量或柔软黏土。

禁止把角色改成人类、动物、机器人、双腿人物或恐怖鬼怪；不擅自加帽子、武器、翅膀、动物器官或多套服装。L 形路径、节点网络、星点和能量粒子仅为辅助，不必全放。

## 组装顺序

严格按以下顺序写 Prompt：

1. **任务**：用途、受众、单一主题和期望交付。
2. **内容层级**：标题、核心结论、3–6 个模块、关系、必须逐字保留的事实。
3. **布局/比例**：结构、阅读路径、留白和已确认比例。
4. **风格**：编号/名称及该风格的媒介、线条、形状、色彩和光影。
5. **品牌/IP**：开启、关闭或自定义状态；角色锚点、动作、强度及参考图。
6. **语言**：文字语言、短句规则和需保持原文的内容。
7. **禁止项**：不发明数据、不遮挡、不堆字及风格/角色特定禁项。
8. **质量标准**：准确、可读、构图完整、层级清楚、风格统一、适合目标清晰度。

## 信息密度

| 档位 | 结构 |
|---|---|
| minimal / 极简 | 1 标题、1 结论、最多 3 关键词、1 主视觉；以留白和冲击力为主 |
| light / 轻量 | 3–5 模块；每模块 1 短标题、1 短句、1 图标/小插图 |
| standard / 标准 | 4–6 模块；短标题、1–2 句说明及统一关系线 |
| dense / 密集 | 卡片、时间线或分区；仍用短句，正常字号放不下就建议拆图 |

不得用缩小字体、压缩间距或堆叠元素解决超载。

```text

核心结论：【conclusion】

【风格】
使用【编号 + 风格名称】；媒介【…】，线条/形状【…】，配色【…】，背景与光影【…】。

【品牌/IP】
状态：【Loki / 关闭 / 临时 IP / 命名品牌】。角色锚点：【…】；动作【…】；强度【主角/辅助/角落签名】；需要时遵循附加参考图。

【文字与禁止项】
文字使用【语言】；标题完整，正文用关键词和短句，高对比、正常可读字号。不得发明事实、数字或引用，不得生成伪文字/重复文字，不混用图标和字体风格，不增加未要求的价格、二维码、品牌或敏感信息。【追加风格与 IP 禁项】

```

## 最终检查

生成前核对单一主题、事实、层级、密度、比例、风格、语言、IP 状态和禁止项。生成后逐项检查：标题与数字准确；文字可读且无伪字/重复；布局和阅读路径自然；图标、线条、色彩和媒介一致；Loki 保留白发、红眼、顽皮微笑和弯曲幽灵尾巴且不遮挡内容。发现问题只报告，不自行重生成。
