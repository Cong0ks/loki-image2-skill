# README Hero 与页面排版设计

## 目标

把已确认的 Loki Image2 Banner V2 放在 README 首屏，让项目打开后立即形成品牌识别，同时缩短新用户从了解项目到安装和首次调用的路径。

## 页面层级

README 按以下顺序组织：

1. 项目标题与 16:9 Banner。
2. 一句话定位与紧凑页面导航。
3. 快速开始：安装位置、首次调用示例和三个运行模式。
4. 12 套视觉风格预览，仅展示图片，不显示风格标题、Prompt 或生成参数。
5. 主要能力、生成确认、Provider、安全、测试与目录说明。

## Banner

- 使用用户确认的 V2 文件，不重新生成、不修改图片内容。
- 仓库目标路径为 `docs/loki-image2-banner-v2-16x9.png`。
- README 使用仓库相对路径并占满可用内容宽度。
- Banner 前后不重复堆叠营销文案，避免首屏冗余。

## 快速开始

- 保留 `$CODEX_HOME/skills/loki-image2` 安装位置。
- 将三条调用示例压缩到同一个代码块，分别对应 `plan`、`prompt` 和 `generate`。
- 页面导航只链接 README 内已有核心章节，不引入外部站点或徽章服务。

## 风格画廊

- 保留现有 12 张 PNG 和“只展示图片”的约束。
- 使用两列 HTML 表格。
- 同类比例成对排列：竖图、方图、4:3、3:2、16:9、竖图，从而减少同一行高度差。
- 不增加可见图片标题、编号、Prompt、新闻来源或参数。

## 不变范围

- 不修改 Skill、脚本、测试和 Provider 行为。
- 不删除现有 README 的生成确认、安全设计、测试和目录信息。
- 不上传本地 Prompt、metadata、输出目录或参考角色图。

## 验证与发布

- 检查 Banner 和 12 张画廊图片的 README 相对路径全部存在。
- 扫描密钥形态、本机绝对路径与图片元数据。
- 运行 133 项离线测试与 Skill validator。
- `git diff --check` 通过后提交并推送 `main`，再核对远端提交哈希。
